# SQL Analysis
## Multi-Touch Marketing Attribution Project
### Infotact Solutions Internship

## Overview
This folder contains all SQL queries written 
to analyze the marketing touchpoint dataset 
and build attribution models.

## Files
- 01_data_exploration.sql
  → Row counts, date range, channel breakdown,
    data quality checks

- 02_funnel_analysis.sql
  → Overall conversion rate, by channel, 
    by campaign, monthly trend

- 03_attribution_analysis.sql
  → User journey mapping, First-Touch, 
    Last-Touch, Linear Attribution models,
    combined comparison query

## Tools Used
PostgreSQL | pgAdmin | VS Code

## Key Findings
- First-Touch attribution shows which channel 
  first attracts customers
- Last-Touch attribution shows which channel 
  closes conversions
- Linear Attribution fairly distributes credit 
  across all touchpoints, revealing a more 
  complete picture than last-click alone
