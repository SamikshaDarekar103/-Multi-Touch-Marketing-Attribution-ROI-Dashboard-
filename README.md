# 📊 Multi-Touch Marketing Attribution & ROI Dashboard

## 📌 Project Overview

This project analyzes marketing campaign performance using **SQL** and **Power BI** to measure **Return on Investment (ROI)** and understand customer journeys across multiple marketing channels. The dashboard helps identify high-performing campaigns, optimize marketing spend, and support data-driven business decisions.

---

## 🎯 Objectives

- Analyze marketing campaign performance
- Measure ROI and conversion metrics
- Compare marketing channels
- Track customer journey and attribution
- Build an interactive Power BI dashboard

---

## 🛠️ Tech Stack

- MySQL
- Power BI
- Excel (CSV Dataset)
- Git & GitHub
